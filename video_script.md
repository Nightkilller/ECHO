# 🎬 ECHO Video Demo Script (60-90 Seconds)

This is a comprehensive, production-ready script for presenting **ECHO** on LinkedIn, Twitter/X, or GitHub. It includes visual cues, narration/voiceover, and on-screen demonstration actions.

---

## ⏱️ Video Breakdown

*   **Total Duration**: ~75 seconds
*   **Format**: Short-form video (suitable for LinkedIn / YouTube Shorts / Twitter video)
*   **Audio Style**: Upbeat, clean, and confident.

---

### **Scene 1: The Problem (0:00 - 0:10)**
*   **Visual**: Screen recording of a cluttered macOS desktop. The user is clicking around, searching, looking frustrated.
*   **Voiceover (VO)**: 
    > "How much time do you waste every day hunting for folders, searching for apps, or manually resizing windows? What if your cursor could do the heavy lifting for you?"

---

### **Scene 2: Introducing ECHO (0:10 - 0:22)**
*   **Visual**: Click on the status bar icon. The elegant borderless onboarding panel floats down smoothly.
*   **VO**:
    > "Meet **ECHO**—a smart, native macOS companion guided by voice or text. Designed with a status-bar-attached interface, it stays pinned exactly when you need it and guides you through onboarding seamlessly."

---

### **Scene 3: The Circular Magnifying Lens (0:22 - 0:38)**
*   **Visual**: User types or speaks: *"Where is the KURSOR folder?"* 
    The blue cursor flies smoothly across the screen, snaps to the target folder, and a high-contrast circular overlay magnifies the folder by 1.3x.
*   **VO**:
    > "Need to locate a file or folder? Just ask. ECHO glides to the target and projects a 1.3x circular magnifying spotlight, making it impossible to miss."

---

### **Scene 4: Action-Smart Window Controls (0:38 - 0:50)**
*   **Visual**: User types or speaks: *"Maximize this window"*, then *"Tile this window to the right"*. 
    The window instantly resizes and snaps. Note that **no magnification** is displayed for these action-based commands.
*   **VO**:
    > "It’s action-smart, too. Tell ECHO to maximize, minimize, or snap windows left and right. It automatically bypasses the magnifier for action commands, completing tasks with zero visual clutter."

---

### **Scene 5: Native Genie Unminimize & Apps (0:50 - 1:02)**
*   **Visual**: Spotify is minimized in the macOS Dock. User types or speaks: *"Open Spotify"*. 
    Spotify immediately flies out of the Dock using the native macOS Genie unminimize animation.
*   **VO**:
    > "Even restoring minimized apps feels premium. ECHO triggers native macOS Genie and Scale animations to pull your apps back from the Dock instantly."

---

### **Scene 6: Call to Action & Collaboration (1:02 - 1:15)**
*   **Visual**: The GitHub repository page for ECHO. Text on screen: *"An inspired open-source project. Let's build!"*
*   **VO**:
    > "ECHO is an inspired project built to push macOS automation boundaries. I'm actively working to make it even more powerful. Check out the codebase on GitHub, drop a star, and feel free to join the journey!"

---

## 💡 Production Tips for Recording
1.  **Cursor Speed**: Ensure the companion cursor speed in settings is set to a natural speed so viewers can track the movement easily.
2.  **Zoom In**: Zoom your screen recording slightly (108p or 4K capture scaled) so the text and circular magnifier detail are crisp.
3.  **High Frame Rate**: Record the video at 60 FPS to capture the smooth unminimizing Genie transitions and custom cursor glide animations.
